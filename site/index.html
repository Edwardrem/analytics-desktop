Analytics Desktop

A native Mac app for business-intelligence reports. Get and shape data, model it with DAX, and design interactive report pages.

Download Release notes

macOS 15 or later, Apple silicon. Beta.

Get and shape data

Read Excel, CSV, JSON, XML, Parquet, folders, web pages and OData feeds. Connect to SQLite, SQL Server, Azure SQL, PostgreSQL, Redshift, MySQL and MariaDB without installing a driver, and to SharePoint, OneDrive, Dataverse, Azure Storage, Azure Data Explorer and Fabric with a work or school account. Some connectors are still in beta: see Data sources. The Power Query Editor gives you applied steps, merges, pivots, column profiling and the M formula language.

Model it with DAX

Relationships, measures, calculated columns and tables, calculation groups and row-level security, with a DAX query view and a TMDL script view. Over 300 DAX functions.

Design interactive reports

Charts, maps, tables and matrices, slicers, drillthrough, bookmarks and tooltips, on pages laid out the way report authors expect. Export to PDF, CSV or Excel.

Open formats, in Git

Reads and writes Power BI project files (PBIP with PBIR and TMDL), .pbit templates and theme JSON, so reports live as plain text next to your code.

Requirements

  • macOS 15 Sequoia or later
  • A Mac with Apple silicon (M1 or later)
  • A Microsoft account only if you use OneDrive, SharePoint, OneLake, Publish or the Microsoft cloud data sources

This is a beta. Read the known limits before you rely on it.

Opening it the first time

Builds are ad-hoc signed and not notarized by Apple, so macOS asks before it opens the app the first time.

  1. Unzip the download and move Analytics Desktop to Applications.
  2. Open it. macOS says it can’t verify the developer. Click Done.
  3. Open System Settings ▸ Privacy & Security, scroll to Security and click Open Anyway next to Analytics Desktop.

Or, in Terminal: xattr -dr com.apple.quarantine "/Applications/Analytics Desktop.app". You only do this once; updates install from inside the app. Getting started
