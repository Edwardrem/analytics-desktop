Privacy

Analytics Desktop has no telemetry. It doesn’t collect usage data or crash reports, and it has no account with this project. Your reports and data stay on your Mac unless you choose to send them somewhere.

When the app goes online

The app makes network requests only for these, and only to the hosts named:

  • Update checks go only to GitHub (api.github.com, and github.com and objects.githubusercontent.com for downloads). They send nothing beyond the request itself. You can turn them off. See Updates.
  • Data sources you connect to, such as a web page or OData feed, are read from wherever you point them.
  • Microsoft services, only after you sign in: opening and saving in OneDrive or SharePoint, the OneLake catalog, Publish to the Power BI service, and sensitivity labels. Publish uploads the model and report definitions, without data. See Microsoft account.
  • The assistant, only if you add your own Anthropic API key and use it. Your question goes to Anthropic’s API with the parts of the report and model it needs to answer, which can include table and column names, formulas and query results.

Nothing else leaves your Mac. In particular, data is never uploaded unless you publish, save to the cloud, or use the assistant.

On your Mac

  • Microsoft sign-in tokens and your Anthropic API key are kept in the macOS Keychain. Microsoft tokens are sent only to Microsoft hosts.
  • Diagnostic tracing is off unless you turn it on in Settings ▸ Diagnostics. Traces record timings and row counts, never values, and stay in a local folder.
  • Python and R scripts run on your own interpreter, and only after you allow scripts.
  • The local agent server (Settings ▸ Developer) is off by default. When on, it listens only on your Mac and needs a token for each session.

This website

This site is static and hosted on GitHub Pages. It uses no cookies and no analytics. The Home and Releases pages ask GitHub’s public API for the list of releases from your browser, and keep the answer for ten minutes in your browser’s session storage. GitHub’s own privacy statement covers its servers.
