Data sources

Choose Get Data on the Home tab of the ribbon. Sources the app can read are listed normally; sources it can’t read yet are shown dimmed with the reason, and can’t be started.

Recent sources remembers your last 20 sources and reconnects with the location filled in.

Sign-in to sources

In this beta the app reads data sources without credentials: local files, and web and OData URLs that need no sign-in. It can’t yet pass a user name, key or Microsoft account to a source. This is listed among the known limits.

What isn’t available

Connectors that need a database driver or an online service the app doesn’t include are listed but dimmed, with the reason in their tooltip. They include SQL Server, Oracle, PostgreSQL, MySQL and other databases, ODBC and OLE DB, Parquet, PDF, .xls and .xlsb, SharePoint lists and folders, Azure, Dataverse and Fabric sources, and custom .mez connectors. Typing one of their M functions fails with a message that it isn’t available.

Import and DirectQuery

  • Import is the default. The rows are saved in your .facet file.
  • DirectQuery works for SQLite. The table is read on load and on refresh, and visuals are computed on your Mac; it is not one SQL query per visual.
  • Dual can be chosen, and behaves as Import.

Refresh

Home ▸ Refresh reloads every table. You can also refresh one table, refresh only the visuals, or refresh the preview inside the Power Query Editor. Automatic page refresh re-queries a page at an interval while the window is open.

Privacy levels and native queries

  • Each source can be given a privacy level (Private, Organizational or Public) in Data source settings. The query engine then refuses to combine data in a way that could send private data to another source, unless you choose to ignore privacy levels in Settings ▸ Security.
  • A SQL statement you type for SQLite runs only after you approve it. Approvals are remembered per source.
