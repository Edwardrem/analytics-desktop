Getting started

Analytics Desktop runs on macOS 15 Sequoia or later, on a Mac with Apple silicon. It is a beta: check the known limits first.

Install

  1. Download the latest zip from the Releases page.
  2. Open the zip (Safari unzips it for you) and drag Analytics Desktop into your Applications folder.

Open it the first time

Releases are ad-hoc signed and are not notarized by Apple, because the project has no Apple Developer ID yet. macOS therefore blocks the first open of a downloaded copy.

  1. Open Analytics Desktop. macOS says it can’t verify that the app is free of malware. Click Done.
  2. Open System Settings ▸ Privacy & Security. Under Security, click Open Anyway next to the Analytics Desktop message, then confirm with your password.

On macOS 15, Control-clicking the app and choosing Open no longer skips this check, so use System Settings. If you prefer Terminal, this removes the download mark instead:

xattr -dr com.apple.quarantine "/Applications/Analytics Desktop.app"

You do this once. Later versions install from inside the app and are checked with the project’s own signature; see Updates.

Your first report

  1. To look around with data straight away, choose Data ▸ Load Sample Data.
  2. To use your own data, choose Get Data on the Home tab of the ribbon and pick a source, such as an Excel workbook or a CSV file. See Data sources.
  3. In the Navigator, tick the tables you want. Choose Load, or Transform Data to clean them first in the Power Query Editor, then Close & Apply.
  4. Pick a visual in the Visualizations pane and drag fields onto it from the Data pane.

The views down the left side of the window are the same as in Power BI Desktop for Windows: Report, Table, Model, DAX query and TMDL.

File ▸ Export to PDF… writes every visible page, and each visual can export its data as CSV, Excel or JSON.

Optional extras

  • Microsoft account. For OneDrive, SharePoint, the OneLake catalog, Publish, sensitivity labels and the Microsoft cloud data sources. See Microsoft account.
  • Assistant. Chat about your data, write and explain DAX, and summarise pages. It uses your own Anthropic API key, entered in Settings ▸ Assistant and kept in the macOS Keychain.
  • Python and R. Script sources, steps and visuals run on your installed interpreter once you allow scripts in Settings ▸ Scripting.
